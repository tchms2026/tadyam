# TADYAM 日本株スコア

日本株の候補を「業績 25%・テーマ 20%・割安度 15%・テクニカル 20%・需給 10%・材料 10%」で比較する、ブラウザ完結型の投資分析ダッシュボードです。

## 現在できること

- 今仕込みTOP10
- 4桁コード・会社名・テーマ検索
- 総合点／今仕込み点／上値余地で並べ替え
- 6軸の個別銘柄分析
- 買い・利確・損切りゾーン
- 監視リストと保有株の端末内保存
- CSVによる参考株価の一括更新

## 起動

`index.html` をブラウザで開くだけで利用できます。外部APIキーや有料サービスは不要です。

## 株価CSV

```csv
code,price
1969,4220
4052,612
```

## 注意

現在の銘柄・株価・スコアは試作確認用データです。投資判断を保証するものではありません。ライブデータ取得は次の開発段階で、利用規約を確認できる無料データ源と分離して実装します。
